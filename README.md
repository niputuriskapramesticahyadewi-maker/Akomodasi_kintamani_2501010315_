## Deskripsi Projek
Projek ini mengumpulkan data spasial fasilitas akomodasi pariwisata di **Kecamatan Kintamani, Bali** dari **OpenStreetMap (OSM)** menggunakan **Overpass API** melalui skrip Python.

## Struktur Folder Repositori
- `data/raw/` : Data mentah berformat JSON dari Overpass API.
- `data/interim/` : Data tabular bersih berformat CSV (`akomodasi_kintamani.csv`).
- `notebooks/` : Notebook Google Colab proses ekstraksi data.
- `docs/` : Dokumen kueri, metadata provenance, kamus data, dan perbandingan BPS.
- `reports/` : Dokumen laporan akhir praktikum (`laporan_akomodasi_kintamani.md`).
